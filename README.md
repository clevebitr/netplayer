# NetPlayer

Minecraft multiplayer without the hassle.

NetPlayer is a **NeoForge** mod for Minecraft **1.21.11** that helps you and your friends quickly connect to the same world—no manual port forwarding required.

## Features

- Create a room in one click; friends join directly
- Automatic network handling—no public IP or port mapping needed
- Lightweight and focused on one thing: multiplayer connectivity

## Requirements

| Item | Version |
| --- | --- |
| Minecraft | 1.21.11 |
| NeoForge | 21.11.x |
| Java | 21+ |

Both the host and joining players must install this mod.

## Installation

1. Install the matching NeoForge version.
2. Place `netplayer-<version>.jar` into the `mods/` folder.
3. Launch the game.

## Usage

1. The host enters a world, creates a room, and gets the room info.
2. Send the room info to your friends.
3. Friends join and start playing.
